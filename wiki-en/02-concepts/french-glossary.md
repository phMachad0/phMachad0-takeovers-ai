# French → English glossary

Vocabulary that shows up in the corpus documents. Organized by where you trip over it.

## Documents and entities

| French | English | note |
|---|---|---|
| bilan | balance sheet | but Takeovers uses it for the entire filing — see [[french-accounting-101]] |
| compte de résultat | income statement | literally "account of the result" |
| annexe | notes to the financial statements | where the kEUR trap lives |
| comptes annuels | annual financial statements | the complete package |
| liasse fiscale | tax form bundle | see [[liasse-fiscale]] |
| plaquette | accounts presentation generated by accounting software | see [[plaquette-vs-liasse]] |
| acte | corporate deed (minutes, bylaws) | subject of the *other* challenge |
| greffe du tribunal de commerce | commercial court registry | where filings are deposited |
| exercice | fiscal year | accounting period |
| clôture / exercice clos le | closing / fiscal year ended on | the `fiscal_year_end` |
| dépôt | filing, deposit | the date in the filename |
| expert-comptable | accountant | who prepares the plaquette |
| commissaire aux comptes (CAC) | independent auditor | |
| rapport de gestion | management report | |

## Takeovers schema acronyms

`financial_fields.json` prefixes every `field_key` with the statement it belongs to. These
are English acronyms, not French or Portuguese.

| acronym | expansion | means |
|---|---|---|
| `PL_` | **P**rofit & **L**oss | compte de résultat (income statement) — liasse 2052 / 2053 |
| `BS_` | **B**alance **S**heet | bilan (balance sheet) — liasse 2050 / 2051 |
| `META_` | metadata | non-monetary (only `META_AVG_WORKFORCE`) |
| `_FRGAAP` | **Fr**ench **GAAP** | French accounting standard, as opposed to IFRS |

## Numbers and signs

| convention | meaning |
|---|---|
| `1 802 935` | thousands separator is a **space** |
| `1 802,50` | decimal separator is a **comma** |
| `(52 814)` or `-52 814` | **negative value** — see [[F004-negatives-are-printed-in-parentheses]] |
| `Néant` | "none", "nonexistent" — equivalent to empty, **not to zero** |
| `K€` / `Kilo-euros` | thousands of euros — see [[units-eur-vs-keur]] |
| `HT` / `TTC` | tax excluded / tax included |
